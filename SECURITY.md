# Security Policy

## Supported Versions

The following versions of Hermes Demand Orchestrator are currently being
supported with security updates:

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅ Active development |

## Reporting a Vulnerability

We take the security of Hermes Demand Orchestrator seriously. If you believe
you have found a security vulnerability, please report it to us as described
below.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via email to **security@hermes-agents.dev** (if
available) or open a private security advisory at:

https://github.com/hermes-agents/hermes-demand-orchestrator/security/advisories

You should receive a response within **48 hours**. If for some reason you do
not, please follow up via email to ensure we received your original message.

## What to Include

Please provide the following information in your report:

- Description of the vulnerability
- Steps to reproduce the issue
- Affected versions
- Any potential impact
- Suggested fix (if available)

## Process

After submitting a report:

1. **Acknowledgement** — We will acknowledge receipt within 48 hours.
2. **Triage** — We will assess the severity and impact of the report.
3. **Fix** — A fix will be developed and tested.
4. **Release** — A patched version will be released.
5. **Disclosure** — We will coordinate disclosure of the vulnerability.

We ask that you refrain from public disclosure until we have had a reasonable
opportunity to address the issue.

## Scope

This security policy applies to the `hermes-demand-orchestrator` package and
its official dependencies. Third-party vulnerabilities should be reported to
the respective maintainers.

## Recognition

We value the contributions of the security research community and will
acknowledge reporters (with their permission) in our security advisories.
